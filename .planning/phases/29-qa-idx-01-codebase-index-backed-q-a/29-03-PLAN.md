<objective>
Add the one `VcsProvider` seam method this phase needs — list the default branch's blob paths — on both adapters, and extract the two Phase 15 selection helpers into path-shaped and content-shaped forms the indexer can actually call.

Purpose: the index build needs a list of candidate paths and a way to rank and filter them. The existing selection helpers take a `FileDiff`, which the indexer does not have; a fabricated `FileDiff` type-checks and runs but collapses the ranking to keyword tiers only, silently. This plan closes both gaps at the seam, so the build plan can consume a clean provider-agnostic listing and a real path score.

Output: `listDefaultBranchTree` on the interface and both adapters, `getTree` plus `getRepositoryMetadata` on the GitHub client, `listSrcTree` plus `getRepositoryMetadata` on the Bitbucket client, additive `scorePath` and `isGeneratedContent` exports with the existing functions delegating to them, and two specs.
</objective>
