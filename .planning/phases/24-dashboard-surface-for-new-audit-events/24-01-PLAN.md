<objective>
Surface the new v1.3 `evidence_missing_summary` audit events in the dashboard's job-detail audit trail viewer.

Purpose: Operators debugging evidence issues need to see the aggregate summary events that were added server-side in Phase 21 (EVID-03) but never rendered in the dashboard. This is purely a rendering catch-up -- the server already serves these events through `getJobDetail`.

Output: Four file changes across two source files and two test files. The normalizer maps `evidence_missing_summary` to the existing `evidence_missing` display group. The renderer shows file+pass as identifier, absentCount+notInHunkCount as MetricLines, and up to 20 sample entries with path:line, title, and reason. Unit tests cover the normalizer mapping and groupAuditByStage integration. Browser tests cover three rendering scenarios: populated event, event with `not_in_hunk` reason entries, and event with empty sample.
</objective>
