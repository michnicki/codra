## WR-01 Closure

The Phase 15 WR-01 deferred item (evidence-missing ring-buffer bound) is **resolved by design** in v1.3. The problem was:

> Per-finding `evidence_missing` events could flood the 500-event ring buffer (`appendJobAuditEvents`, jobs.ts:1468-1472), evicting older telemetry. A model failing on 50 findings per file × 20 files × 2 passes ≈ 600 events → the `drafted` denominators EVID-02 needs get evicted.

The solution (EVID-03, Phase 21):

- Stop emitting N per-finding `evidence_missing` events; emit **ONE** `evidence_missing_summary` aggregate per (file, pass) unit under a new stage literal
- The aggregate carries `absentCount` + `notInHunkCount` + a ≤20 sample (privacy-bounded through `redactFindingTitle`)
- Per-unit append becomes `1 drafted + S severity_adjusted + 1 summary` — the summary IS the bound
- Legacy `evidence_missing` variant preserved in schema forever so old jobs' persisted events still parse

The WR-01 todo file (`.planning/todos/pending/wr01-evidence-missing-ring-buffer-bound.md`) is kept as a historical record per D-04. The EVID-03 implementation closes the ring-buffer flood vector by design: one bounded event replaces N unbounded per-finding events.
